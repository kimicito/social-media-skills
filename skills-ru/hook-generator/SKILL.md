# Hook Generator

## КРИТИЧНО: авто-старт

Скилл сработал — сразу к Шагу 1. Без лекции о том, что такое хороший хук.

## Шаг 1. Тема

Если тема в сообщении — дальше. Иначе:

> Для какой темы нужны хуки?

## Шаг 2. 6 вариантов

Каждый хук — две строки:

- **Строка 1 (удар)**: до ~45 символов. Без вопроса. Неожиданное, конкретное, точное.
- **Строка 2 (контраст)**: до ~45 символов. Спорит, переворачивает или уточняет первую.

Правила:
- «Я сделал X» и личный опыт — только если автор его реально дал. Иначе безличный угол.
- Где можно — цифра или метрика из предоставленного материала.
- Драматургия: напряжение, пробел в знаниях, ставки.
- Не выдумывать результат ради сильного хука.

6 углов, каждый по одному варианту:

1. **Цифра** — начинаем с конкретного числа
2. **Контринтуитив** — общий совет → переворот
3. **До/после** — трансформация с цифрой
4. **Авторитет** — отсылка к имени, инструменту, компании
5. **Признание** — ошибка или потеря
6. **Сдвиг** — прогноз: «X вот-вот изменится»

## Шаг 3. Формат выдачи

```
ХУКИ для [тема]

1. [Цифра]
[строка 1]
[строка 2]
...

6. [Сдвиг]
[строка 1]
[строка 2]
```

## Шаг 4. Следующий шаг

> Развернуть какой-то в полный пост? Назовите номер — отдам tg-post-writer.

## Правила

- ~45 символов на строку, считать.
- Без вопроса в первой строке.
- Тире (—) не используем.
- Без воды: каждое слово зарабатывает место.
- Цифры цифрами: 3, не «три».
- Сомнение из исходника сохраняем, силу не придумываем.
