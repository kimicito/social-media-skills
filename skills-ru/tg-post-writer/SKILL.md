# TG Post Writer

## КРИТИЧНО: авто-старт

Скилл сработал — сразу к Шагу 1. Без саммари.

## Шаг 0. Голос

Проверить `about-me.md` и `voice.md` в корне workspace. Если нет — сказать: «Сначала соберём голос: скажите "собери мой голос"», и стоп. Если есть — прочитать оба.

## Шаг 1. Вход

Если тема или «свалка контекста» (заметки, конспект, тезисы) уже в сообщении — использовать. Иначе спросить:

> О чём пост? Можно темой одной строкой или вставить заметки/стенограмму — разберу сам.

## Шаг 2. План и угол

По теме и рубрикам из about-me.md предложить 3 угла (в чате, нумерованным списком), дать выбрать. Параллельно спросить формат:

- **PAS** — проблема → обострение → решение
- **How-to** — нумерованные шаги/приёмы
- **История с выводом** — реальный кейс → урок
- **Контринтуитив** — идём против общего совета, с доказательством

Если канал/площадка из about-me.md подсказывает очевидный выбор — предложить его первым.

## Шаг 3. Черновик

Писать строго по voice.md: ритм, тип зачина, закрытие, все запреты из раздела «Запрещено» и «Чего этот голос никогда не делает». Факты, метрики, цитаты — только из предоставленного материала или проверяемые; не выдумываем ни цифры, ни «личный опыт».

Формат — Telegram:
- Без markdown-таблиц, без заголовков ##; выделение — CAPS или **жирный** дозированно
- Абзацы 1–3 строки, воздух
- Пост: 800–1500 знаков (если не попросили иначе); статья в блог: 1200–2500 слов с подзаголовками
- Хэштеги и engagement-bait («поделитесь, если согласны») — только если есть в образцах голоса

Выдать готовый текст в code block, как его видно в канале. После — 2–3 предложения, почему выбран такой зачин и структура (со ссылкой на конкретные пункты voice.md).

## Шаг 4. Итерация

> Как на вкус? Что поменять — или «ок», сохраняю финал.

Правки — новый code block. Максимум 3 круга. По «ок» сохранить в `content-drafts/YYYY-MM-DD-slug.md` в workspace и сказать, куда сохранено.

## Правила

- Всегда читать оба файла голоса перед письмом.
- Тире (—) не используем в текстах постов.
- Не добавлять эмодзи, если голос их не использует; если использует — держать плотность образцов.
- Не приписывать автору чужой опыт из примеров голоса.
- Если тема за пределами рубрик about-me.md — предупредить и спросить, пишем ли всё равно.
